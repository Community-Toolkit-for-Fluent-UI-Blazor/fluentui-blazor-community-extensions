# Carousel

The `FluentCxCarousel` component is a UI element that displays multiple pieces of content, such as images, cards, or products, within a limited space. Users can navigate through the items horizontally, either manually or automatically.

### Autoplay

The carousel supports autoplay with three different modes:
- **None**: No autoplay
- **Rewind**: After reaching the end, the carousel will jump back to the start
- **Infinite**: Creates a seamless infinite loop
