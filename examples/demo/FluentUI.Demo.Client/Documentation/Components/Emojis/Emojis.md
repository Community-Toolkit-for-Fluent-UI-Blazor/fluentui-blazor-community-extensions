# Emojis

The EmojiPicker component is used to display a list of emojis that users can select from.
It can be used in various contexts, such as chat applications, comment sections, or any other place where users might want to express themselves with emojis.
The component can be customized to show different categories of emojis, and it can also include a search functionality to help users find specific emojis quickly.
You can use specific font icons to represent emojis by providing a custom IEmojiFontProvider implementation.
