# FloatingButton

A floating button is a component that can be placed at a specified position on the relative container. This component can provide quick access to some actions in your app.
The RelativeContainerId of a floating button must be a component with relative position. If the RelativeContainerId isn't set, the position of the `FluentCxFloatingButton` is fixed.
